中间态注记：

- 首次给 profile 补装 chokidar/sdk/js-yaml@5 时，pnpm 重排把原本可解析的 `@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-system-prompt` 从 hoisted 树里挤掉了 → dshx-commands 等反向报缺包；改用显式精确版本补齐后稳定（`description: dshx "依赖随 dsh 自带"` 假设在本 profile 布局下不成立）。
- `dsh plugin --profile web add @deepseek-ai/dsh-tools`（不带版本）被供应链策略拦截：registry 旧线 `0.0.1-rc.1` 与 dsh 0.2.0-rc.2 peer 不兼容 —— 因此所有 dsh 运行时套件必须精确 `@0.2.0-rc.2`。
- 本地给安装副本打乱码修复补丁不持久：后续任意 `dsh plugin add/update` 触发 pnpm 重装会从 GitHub 重新拉回损坏版 —— 修复只能落在仓库源头。
